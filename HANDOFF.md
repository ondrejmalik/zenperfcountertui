## Active Blockers & Known Gotchas

- **Toolchain Pin:** `rust-toolchain.toml` pins `stable` with `rustfmt` and `clippy` so local workstations (which may default to nightly), local Jenkins (`LocalSystem`), and GitHub Actions (`windows-latest`) stay 100% consistent. If your host shell exports nightly `RUSTFLAGS` (e.g. `-Zthreads=...`), `scripts/ci.py` clears it automatically; clear `RUSTFLAGS` if running bare `cargo` commands.
- **Pre-declared v0.1 Workspace Dependencies:** `serde`, `serde_json`, `toml`, `anyhow`, and `clap` are pre-wired in workspace `Cargo.toml` so `v0.1-foundation` worker PRs do not need to edit `Cargo.toml`/`Cargo.lock` (avoiding Tier-2 dependency review gates).
- **Scoped `unsafe` Ratchet:** `zen2top-core` and `zen2top-cli` enforce `#![forbid(unsafe_code)]` and `core_cli_unsafe_blocks == 0`. Win32/ETW FFI in `zen2top-platform` is allowed only with a `// SAFETY:` comment immediately above every `unsafe` block/`unsafe fn` (`platform_undocumented_unsafe == 0`).
